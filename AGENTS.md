# Moodle Batch

Рабочий самостоятельный проект: `batch/`, `batch-extension/`, `tests/batch/`.
Node.js 24, Playwright, встроенный SQLite. Предпочитай короткие изменения без новых зависимостей.

- Используй codebase-memory MCP для поиска кода; если этот новый проект ещё не индексирован, читай известные файлы напрямую.
- Используй Context7 для актуальной документации библиотек и JevRouter при реальном выборе методов, согласно пользовательским инструкциям.
- `.playwright-mcp/` содержит авторизацию, ответы и реальные задания: не коммить и не печатай секреты.
- Сохраняй область Moodle: аккаунт, курс, тест, попытка, вопрос и родные поля отправки.
- Не повторяй отправку запроса модели или Moodle с неизвестным исходом.
- Новые ответы требуют проверяемого источника; уверенность модели сама по себе не является доказательством.
- Подтверждённая Moodle память имеет приоритет; неправильные комбинации сохраняются целиком.
- При работе через личный браузер закрывай только созданные программой вкладки и служебные вкладки подключения Moodle Batch.
- Проверка: `npm test`. Сервис: `npm run batch:serve`.
