### Оставшиеся остановки

Для восьми действующих попыток 388498, 388504, 388506, 388514, 388516, 388518,
388520, 388522 проверены исходные элементы управления: radio/checkbox совпадают
с типами парсера. Ошибки распознавания одиночного выбора не обнаружено.
Материалы этих тем доступны, объём 11708–42750 символов; весь материал каждой
темы помещается в лимит контекста Web. Для Jev лимит меньше, поэтому возможны
выдержки. Статус ready означает успешное чтение обнаруженных материалов,
но не доказывает полноту обнаружения материалов всего курса.

В некоторых одиночных вопросах цитаты поддерживают несколько вариантов; в
других не подтверждают существенное слово или направление отношения. Нельзя
объявлять ошибку ключа Moodle только на основании ответа модели. Для снятия
таких остановок нужен различающий источник, уточнение формулировки или
раскрытый правильный ответ Moodle. Неверные комбинации сохраняются в памяти;
отсутствующий ключ не восстанавливается перебором ради оценки.

Независимая проверка теперь объясняет конкретный проблемный вариант и различает
противоположный вывод, недостаток контекста, низкую уверенность и некорректный
ответ проверяющей модели. Это диагностика для уточнения, не новое доказательство.

## Восстановление незавершённых ответов ChatGPT — 18 октября

Обнаружен общий дефект: ошибка чтения, проверки источников или независимой
проверки оставляла внешний запрос в `pending`. Следующий запуск блокировал
тест до попытки прочитать уже завершённую исходную беседу.

Теперь общий предварительный этап восстанавливает полный исходный пакет,
включая случай выбора одного теста из него. Повторной отправки ChatGPT нет.
Исходные ID, порядок родителей, формулировки, варианты, память ответов и
привязки сохраняются; перед использованием проверяются текущая попытка,
контекст и исходный fingerprint. Неизвестный результат независимой проверки
не обходится изменением состава пакета. Готовое `needs_review`, включая
Instant, которому требуется повышенная проверка, сохраняется как результат,
а не запускает новый Instant для тех же вопросов.

Перед отправкой сохраняются исходный запрос и параметры продолжения;
после чтения — ответ и адрес беседы, затем результаты проверки источников.
Ошибка сохраняет этап сбоя. Последующий запуск может продолжить обработку
локального ответа, не открывая браузер для повторного чтения.

Все десять исходных привязок сопоставлены с текущими попытками через GET.
