# Moodle Batch

Отдельный проект для решения Moodle-тестов через запросы: память ответов → Jev →
GPT Web, затем штатная отправка попытки и проверка обратной связи Moodle.

## Запуск

Требуются Node.js 24 и установленное Playwright Extension в браузере с авторизацией ChatGPT.

```powershell
cd D:\Users\Downloads\moodle-batch
npm ci
npm run batch:serve
```

Рабочая папка расширения: `.playwright-mcp/batch/extension`.
Кнопка «Moodle Batch» на страницах Moodle открывает выбор тестов и историю запусков.
При переносе проекта уже установленное расширение продолжает обращаться к тому же
локальному сервису. Для последующих обновлений загрузите расширение из новой папки.

## Как решаются тесты

- Уже подтверждённые Moodle ответы берутся из SQLite без обращения к моделям.
- Вопросы выбранных тестов объединяются в пакеты с отдельным контекстом каждого теста.
- Web начинает с Instant; неподтверждённые вопросы уточняются в том же чате в Medium и High.
- Новому ответу нужна проверяемая цитата из материала или публичного интернет-источника.
- JavaScript-источники читаются в отдельном контексте браузера без личной авторизации.
- Проверенные ответы незавершённой попытки сохраняются при изменении пакета.
- Тест отправляется только при наличии ответов на все вопросы; результат обновляет память.
- Ошибочные комбинации сохраняются и исключаются из следующих попыток.

Совпадение цитаты подтверждает её происхождение. Правильность трактовки окончательно
проверяется обратной связью Moodle; недоступный или неоднозначный источник может остановить тест.

## Файлы

- `batch/` — запросы, память, провайдеры и локальный сервис.
- `batch-extension/` — интерфейс расширения.
- `tests/batch/` — проверки движка, сервиса и расширения.
- `.playwright-mcp/` — локальная авторизация, база, кеш и журналы; исключена из Git.

Проверка проекта: `npm test`.

Проверено 46 тестами; живые попытки 308230 и 308235 завершены на 100%.

Если сессия Moodle истекла, панель сохраняет оценки и историю. Обновите
`.playwright-mcp/reference-auth/cookies.json` и нажмите «Обновить анализ»:
сервис проверит тот же аккаунт и восстановит работу без перезапуска.
